Design System, sanitized portfolio build. Logos are neutral placeholders.

The problem

Web pages and generated artifacts drifted from the agency brand.

The solution

One source of truth: src/tokens.css, mirrored in src/theme.js and tailwind.config.js, consumed by a small React component library and documented in design-system.md.

Highlights

What it does well

  • Palette, type scale, spacing, radius and elevation tokens with WCAG AA usage rules
  • 10 components (Badge, Button, Card, Footer, Hero, Input, NavBar, QuoteCTA, ServiceTile, Testimonial), barrel-exported from src/components/index.js
